> Deploy Prometheux as a native application in your Databricks workspace, on AWS,
> Azure, or GCP.

## Overview

The Prometheux Databricks App is a **lightweight frontend** (a React UI served by
a small Node.js proxy) that installs directly into your workspace.

<Card title="Prometheux Databricks App repository" icon="github" href="https://github.com/prometheuxresearch/prometheux-databricks-3p-app">
  github.com/prometheuxresearch/prometheux-databricks-3p-app
</Card>

<Note>
**Your data and compute never leave Databricks.** Your tables stay in Unity
Catalog under your governance, and all processing runs on your own Spark
clusters. Prometheux Cloud only handles orchestration, the structure and
definitions of your projects, and sign-in — it never stores your table data.
</Note>

## How it works

| What | Where it runs | What it does |
| --- | --- | --- |
| **Your data** | Unity Catalog (your workspace) | Stays put, governed by Unity Catalog. |
| **Processing** | Your Databricks Spark clusters | The Prometheux Engine runs Vadalog **next to your data** as a cluster library. |
| **Orchestration** | Prometheux Cloud | Coordinates reasoning, stores the structure and definitions of your projects, manages sign-in. Never sees your raw tables. |
| **Frontend** | Databricks App in your workspace | Stateless UI — nothing persistent is stored in the app. |

```

                              |
+-------------------------------------------------------------+
|                 YOUR DATABRICKS WORKSPACE                   |

                              v

+-------------------------------------------------------------+
```

## Deployment

### Deploy via Git (recommended)

1. In your workspace, open **Compute → Apps → Create App**, choose **Custom**,
   name it (e.g. `prometheux`), and wait until it is **Active**.
2. Click **Deploy** → **From Git** and fill in:
   - **Repository URL:** `https://github.com/prometheuxresearch/prometheux-databricks-3p-app`
   - **Reference type:** Branch · **Git reference:** `main`
   - **Source code path:** `src`
3. Click **Deploy**.

<Warning>
**Source code path** must be `src` (the `app.yaml` manifest lives there). Leaving
it empty causes *"No command to run and no Python file found"*.
</Warning>

Your app will be available at `https://prometheux-<workspace-id>.databricksapps.com`.
To update, open the app and click **Deploy** again — Databricks pulls the latest
commit on `main`.

### Deploy via Databricks CLI (alternative)

For environments that can't reach GitHub from the workspace:

```bash
git clone https://github.com/prometheuxresearch/prometheux-databricks-3p-app.git
cd prometheux-databricks-3p-app
./deploy.sh
```

## Authentication

The app runs with authentication enabled. On first open, Prometheux signs the
user in automatically using their Databricks identity (zero-click) — no passwords.
Each Databricks workspace becomes its own Prometheux organization. A Prometheux
administrator approves the first access request per user.

## Processing engine

Vadalog runs on **your** Spark clusters via the **Prometheux Engine**, installed
as a cluster library, so compute happens next to your data. The app accesses your
clusters and Unity Catalog tables through a **Service Principal** you configure in
the app's Databricks settings.

<Warning>
The Prometheux Engine is provisioned by Prometheux. If your workspace isn't yet
enabled, request access from the app's **Installation** tab or at
[support@prometheux.ai](mailto:support@prometheux.ai).
</Warning>

See [Installing PX on Databricks & Connectors](/get-started/installation/databricks/connectors)
for engine installation and connecting to Unity Catalog.

## Network egress

The app contacts only three hosts at runtime:

| Host | Purpose |
| --- | --- |
| `<your-workspace>` (`*.cloud.databricks.com` / `*.azuredatabricks.net` / `*.gcp.databricks.com`) | Your workspace API (SCIM, Clusters, Libraries, Jobs) |
| `auth.prometheux.ai` | Sign-in (zero-click SSO) |
| `api.prometheux.ai` | Reasoning orchestration |

If your workspace restricts outbound traffic (e.g. a Serverless Egress Gateway),
allowlist the two `prometheux.ai` hosts. No analytics, ad networks, CDN scripts,
or external secret stores are contacted.
